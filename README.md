# BudgetBuddy
# Overview
BudgetBuddy is a Python desktop application developed using Object-Oriented Programming (OOP) and Tkinter GUI to help users track daily expenses and manage monthly budgets.
# Features
1) Add, edit and delete expenses
2) Search and sort records
3) Monthly expense summary
4) Budget limit alerts
5) Password protection
6) Graphical spending reports
7) CSV-based data storage
# Technologies Used
1) Python
2) Tkinter
3) Object-Oriented Programming
4) CSV
5) Matplotlib
